# Sicherheitsmeldungen

Bitte mögliche Sicherheitslücken in MaStunden vertraulich melden. Keine ausnutzbaren Details, echten Passwörter, Tokens oder personenbezogenen Daten in öffentlichen Issues veröffentlichen.

## Privater Meldeweg

Wenn auf der [Security-Seite](https://github.com/MJnms1980/MaStunden/security) die Schaltfläche **Report a vulnerability** verfügbar ist, bitte diese verwenden. Andernfalls über die Kontaktmöglichkeit auf [www.it-janz.de](https://www.it-janz.de) eine vertrauliche Meldung an IT-Janz senden. Ist für einen Nachweis die Übertragung vertraulicher Daten erforderlich, zunächst einen geeigneten Übertragungsweg abstimmen.

Hilfreich sind:

- betroffene Version oder Commit und betroffene Komponente;
- nachvollziehbare Schritte mit ausschließlich synthetischen Testdaten;
- erwartetes und tatsächliches Verhalten sowie mögliche Auswirkungen;
- ein Lösungsvorschlag, falls vorhanden.

Bitte möglichst mit dem aktuellen Stand reproduzieren. Es gibt derzeit keine zugesicherte Reaktionsfrist oder garantierte Wartung älterer Versionen. Veröffentlichte Fehlerbehebungen werden in den jeweiligen Änderungen beziehungsweise Releases dokumentiert.

Falls echte Zugangsdaten versehentlich veröffentlicht wurden, diese unverzüglich beim betroffenen Dienst sperren oder ersetzen. Das Löschen einer Datei allein macht veröffentlichte Zugangsdaten nicht wieder sicher.
